# 영화 직업 카드 스튜디오

초등학교 4학년 영화 직업 탐구 및 교실 게시용 카드 제작 앱입니다.

## GitHub · Vercel 배포
1. ZIP 파일의 압축을 풉니다.
2. GitHub에 새 저장소를 만들고 압축 안의 파일과 assets 폴더를 올립니다. index.html이 저장소 첫 화면에 보이도록 올립니다.
3. Vercel에서 해당 GitHub 저장소를 가져옵니다.
4. Framework Preset은 Other로 선택합니다. Build Command와 Output Directory는 별도로 지정하지 않습니다. Root Directory는 저장소 루트입니다.
5. 배포된 주소를 학생들에게 공유합니다.

환경 변수, Firebase, API 키, 학생 로그인은 필요하지 않습니다. 카메라는 HTTPS로 배포된 주소에서 사용하며, 기기의 카메라 권한을 허용해야 합니다. 사진 파일 업로드도 가능합니다.

## 수업 흐름
직업 탐색 → 사진 촬영 또는 업로드 → 사진 크기·위치·회전 조절 → 조사 내용 입력 → 카드 PNG 저장 또는 인쇄

8가지 직업: 영화감독, 영화배우, 촬영 감독, 음향 감독, 조명 감독, 미술 감독, 영화 편집자, 시나리오 작가.
사진은 직업 그림의 얼굴 영역에 맞추는 방식이며 AI 얼굴 합성 서비스는 사용하지 않습니다.
사진은 외부 서버로 전송하지 않습니다. 입력한 글과 선택값은 같은 브라우저에 남을 수 있으므로 공용 태블릿에서는 새로 만들기를 눌러 다음 학생이 시작합니다. 사진은 새로고침하면 사라집니다.

완성 카드: 1240 × 1754px PNG, A5 세로 비율. 인쇄 기능은 A4 용지 가운데 A5 크기로 배치합니다.

## 구성
index.html: 화면과 디자인
app.js: 직업 자료, 사진 조절, 카드 생성 및 저장
assets/: 직업 그림과 한글 글꼴
vercel.json: 정적 웹앱 설정

별도 설치나 빌드 없이 동작하는 정적 웹앱입니다. 다른 서비스로의 이미지 자동 제출·교사 수집 기능은 포함하지 않습니다.

## 귀여운 일러스트 업데이트 (2026-10-30)
- 8개 직업마다 인물 그림 2개, 총 16개. 성별 글자 대신 그림 1·그림 2로 선택합니다.
- 새 촬영장 배너, 파스텔 색상, 그림이 들어간 직업 선택 화면을 적용했습니다.
- 사진이 없을 때는 기본 일러스트 얼굴을 사용합니다. 업로드하면 얼굴 부분에 사진을 맞출 수 있습니다.
- 직업별 작업 단계, 협력하는 사람, 작은 체험, 자료 관찰 질문을 추가했습니다.
- 직업 관련 기사·인터뷰, 한국영상자료원 교육 영상 모음, 교육부·스스로넷 영상 링크를 넣었습니다. 유튜브 검색 링크는 검색 결과임을 따로 표시했습니다.
- 외부 자료는 긴 강연이나 중고등학생 대상 자료도 포함되어 있어 교사가 필요한 부분을 골라 활용합니다. 지난 교육 공지는 신청용이 아닌 역할 소개 참고 자료입니다.
- research.js에 직업별 확장 설명과 자료 링크가 있습니다. 영상은 외부 링크로 열리며 앱에 영상 파일을 복제하지 않았습니다.

### 업데이트 방법
기존 GitHub 저장소에 ZIP 안의 파일들을 같은 위치에 덮어쓰고 커밋합니다. assets 폴더의 새 그림 3개와 research.js도 반드시 올려 주세요. 연결된 Vercel 프로젝트에서 새 커밋을 배포합니다. 앱 화면이 그대로 보이면 브라우저를 강력 새로고침합니다.

## 태블릿 화면 업데이트
앱 전체를 기기 화면 높이에 고정했습니다. 직업 탐색에서는 소개·현장·체험·영상·기사를 눌러 보고 이전/다음으로 넘깁니다. 자료를 한꺼번에 펼치는 긴 화면을 제거했습니다. 사진 도구와 하단 이동 버튼은 한 화면에 배치합니다. 조사 내용은 만든 사람·하는 일·필요한 능력·해보고 싶은 일을 한 항목씩 입력하고 자료 보기는 별도 페이지형 창으로 엽니다. 화면 키보드로 표시 높이가 바뀌면 사용 가능한 높이에 맞춰 배치합니다. 외부 사이트는 해당 사이트의 화면 구성에 따라 스크롤이 있을 수 있습니다.
1024×600 가로 화면과 800×1000 세로 화면 배치를 확인했습니다.

## 가독성·설명 보강 업데이트
본문·직업 이름·탭·이동 버튼·입력 안내·자료 링크 글씨를 키웠습니다. 인물 선택은 남·녀로 표시합니다. 직업별로 장면 예시, 필요한 능력과 이유, 도구 설명, 알아둘 점을 추가해 자료를 12~14쪽으로 구성했습니다. 소개·능력·현장·체험·영상/기사 탭으로 이동하고 이전·다음으로 넘깁니다.
이번 수정 파일은 app.js와 index.html입니다. 전체 ZIP을 덮어써도 됩니다.
