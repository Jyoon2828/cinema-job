# 영화 직업 카드 스튜디오

초등학교 4학년 영화 직업 탐구 및 직업 카드 제작 앱입니다.

## GitHub · Vercel 배포

1. 저장소 루트에 `index.html`, `app.js`, `research.js`, `vercel.json`, `assets/`를 함께 올립니다.
2. Vercel에서 GitHub 저장소를 가져오고 Framework Preset을 Other로 선택합니다.
3. Root Directory는 저장소 루트입니다. 별도 설치·빌드·환경 변수·Firebase·학생 로그인은 필요하지 않습니다.
4. 배포 주소를 학생들에게 공유합니다. 연결된 저장소에 커밋하면 Vercel이 새 버전을 배포합니다.

카메라는 HTTPS 배포 주소와 기기 권한이 필요합니다. 사진 불러오기도 사용할 수 있습니다.

## 수업 흐름

직업 탐색 → 사진 넣기 또는 아바타 꾸미기 → 조사 내용 정리 → 카드 PNG 저장

8가지 직업은 영화감독, 영화배우, 촬영 감독, 음향 감독, 조명 감독, 미술 감독, 영화 편집자, 시나리오 작가입니다. 직업 자료는 소개·능력·현장·체험·직업 자료 탭과 이전·다음 버튼으로 한 화면씩 읽습니다. 영상 링크는 제거하고 직업정보 및 기사 자료를 연결했습니다.

조사 내용은 만든 사람·하는 일·필요한 능력과 태도·해보고 싶은 일을 한 항목씩 입력합니다. 필요하면 자료 보기 창을 열 수 있습니다.

## 아바타 꾸미기

- 메뉴: 머리·눈·입·액세서리·옷 색깔 5가지.
- 남자: 기본 짧은 머리 1종으로 고정합니다. 여자: 머리 5종을 선택합니다.
- 눈: 기본 여자 직업카드와 같은 그림체의 뜬눈·웃는 눈 2종. 기본 남자 직업 그림 8개의 눈도 같은 형태로 통일했습니다.
- 입: 살짝 웃기·활짝 웃기 2종.
- 액세서리: 안경·모자·머리핀을 각각 선택하며 함께 착용할 수 있습니다. 안경은 정면 테만 표시합니다. 야구 모자·벙거지 모자는 각각 크기와 높이를 맞추며 직업별 머리 위치를 따라갑니다.
- 옷 색깔: 원래 색과 하늘색·초록색·보라색·분홍색·주황색. 의상 모양과 채색 질감을 유지하며 피부·손·도구는 제외합니다. 밝은 옷감과 소매 주름도 함께 색을 바꾸며, 앞쪽 손·장비를 그릴 때 원래 옷 색이 덮이지 않도록 처리합니다.
- 얼굴형·피부색·눈썹·코·머리색 선택은 제거했습니다. 이전 버전의 꾸미기 설정은 새 기본값으로 전환하며 조사 글은 유지합니다.

얼굴 부품을 서로 다른 화풍으로 혼합하지 않고, 원래 직업카드와 같은 채색으로 제작한 머리·얼굴과 네 가지 눈/입 조합을 사용합니다. 같은 그리기 함수를 선택창, 편집 화면, 저장 카드에 적용합니다.

## 저장과 개인정보

완성 카드는 1240×1754px PNG, A5 세로 비율로 저장합니다. 인쇄 버튼은 없습니다. 저장한 이미지는 기존 패들렛 등으로 학생이 제출합니다. 자동 제출·교사 수집 기능은 포함하지 않습니다.

사진은 기기 안에서 처리하며 서버로 보내지 않습니다. 사진은 새로고침하면 사라집니다. 조사 글과 선택값은 같은 브라우저에 남으므로 공용 기기는 활동 후 ‘새로 만들기’를 사용합니다. 사진은 AI 합성 없이 그림의 얼굴 영역에 맞추는 방식입니다.

## 태블릿 화면

1024×600 가로와 800×1000 세로 화면에서 전체 스크롤과 하단 버튼 잘림을 확인했습니다. 긴 자료와 조사 항목은 버튼으로 넘겨 봅니다. 외부 자료 사이트의 화면 구성은 해당 사이트를 따릅니다.

## 주요 파일

- `index.html`: 화면·반응형 배치·도움말
- `app.js`: 활동 흐름·사진 편집·아바타 조합·의상 색 변경·카드 저장
- `research.js`: 직업별 확장 설명·직업정보/기사 링크
- `assets/careers-male-v3.webp`, `assets/careers-1.png`: 기본 남녀 직업 그림
- `assets/avatar-v3/`: 통일한 화풍의 머리·표정·액세서리. 새 벙거지 그림 `hat-bucket-v2.webp`도 함께 업로드해야 합니다.
- `assets/avatar-costumes-0.webp`, `assets/avatar-costumes-1.webp`: 아바타용 남녀 의상
- `ASSET_NOTES.md`: 그림 제작 기록
- `vercel.json`: 정적 배포 설정
