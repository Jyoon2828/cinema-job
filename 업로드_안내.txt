꿈꾸는 영화 제작소 · 옷 디테일과 직업 탐색 수정본

1. 이 압축파일을 풉니다.
2. 압축 안의 전체 파일과 assets/ 폴더를 기존 GitHub 저장소 루트에 같은 이름과 경로로 교체합니다.
3. 기존 Vercel 설정은 그대로 사용합니다.
4. 새 배포가 완료되면 브라우저를 새로고침합니다.

이번 수정
- 직업별 옷의 그림자·주름·옷깃·소매·장비 주변에 남던 원래 색을 보정했습니다.
- 손·피부와 직업 도구, 검은 안쪽 옷을 보호합니다.
- 직업 탐색은 남자 그림 4개와 여자 그림 4개를 섞어 총 8개 직업을 보여 줍니다.
- 직업 탐색에서는 성별을 구분하거나 선택하지 않습니다.
- 얼굴 꾸미기 단계에서 남·여를 선택합니다. 녀 표기는 여로 고쳤습니다.
- 전체 화면 일러스트와 기존 글씨체, 기본 모자 없음, 저장한 조사 글과 꾸미기는 유지합니다.
