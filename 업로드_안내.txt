영화 직업 카드 · 모자 기본값 수정본

1. ZIP의 압축을 풉니다.
2. GitHub cinema-job 저장소에서 Add file → Upload files를 엽니다.
3. 압축 안의 index.html, app.js, research.js, vercel.json과 assets 폴더를 저장소 루트에 함께 올려 기존 파일을 교체합니다.
4. Commit changes를 누르면 연결된 Vercel에서 새 버전을 배포합니다.
5. 배포 완료 후 페이지를 새로고침합니다.

모자는 기본적으로 ‘없음’으로 시작합니다. 이전 버전에서 저장되어 자동 복원되던 모자는 해제합니다.
머리·눈·입·안경·머리핀·옷 선택과 조사 글은 유지합니다.
모자는 모자 메뉴에서 직접 선택한 경우에만 착용하고 저장합니다.
‘골고루 바꾸기’는 모자를 자동으로 추가하지 않습니다. 안경 예시에도 모자가 따라 나오지 않습니다.

기존 옷 색상 보정, 남자 머리 3종과 벙거지 착용 보정도 포함합니다.
전체 파일을 함께 교체하면 필요한 이미지도 모두 반영됩니다. 별도 설치·빌드·로그인·API 키·환경 변수·Firebase는 필요하지 않습니다.
