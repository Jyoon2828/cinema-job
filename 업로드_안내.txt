영화 직업 카드 스튜디오 — 수정본 업로드 안내

1. 이 ZIP 파일의 압축을 풉니다.
2. 기존 GitHub 저장소 Jyoon2828/cinema-job을 엽니다.
3. Add file → Upload files를 선택합니다.
4. 압축을 풀어 나온 index.html, app.js, research.js, vercel.json, assets 폴더 등 내용물을 저장소 맨 위에 함께 올립니다.
   ZIP 파일 자체나 바깥 폴더 하나를 통째로 올리는 방식이 아닙니다.
   새 그림이 들어 있는 assets/avatar-v3 폴더와 assets/careers-male-v3.webp도 반드시 포함합니다.
5. Commit changes로 저장합니다. Vercel 자동 배포가 연결되어 있으면 새 커밋이 배포됩니다.
6. 배포가 끝나면 웹앱을 새로고침합니다.

이 파일은 수정 코드와 실행에 필요한 그림·글꼴을 모두 포함한 전체 프로젝트입니다.
Firebase, API 키, 환경 변수, 설치·빌드 작업은 필요하지 않습니다.
기존 저장소의 오래된 그림 파일은 남아 있어도 실행에 영향을 주지 않습니다.
